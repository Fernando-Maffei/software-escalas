# Central de Escalas — como usar

## Como acessar

Abra o navegador (Chrome ou Edge) e digite o endereço do sistema:

```
http://192.168.0.50:4450
```

> Troque `192.168.0.50` pelo endereço que o responsável passou.
> **Dica:** salve nos favoritos para não digitar toda vez.

Faça login com seu usuário e senha. Pronto.

---

## Deixar o sistema com "cara de aplicativo" (ícone na área de trabalho)

Dá para criar um **ícone** que abre a Central de Escalas em **janela própria**, sem a
barra do navegador — parece um programa instalado.

### No Chrome
1. Abra o sistema no navegador.
2. Clique nos **três pontinhos** (canto superior direito).
3. Vá em **"Salvar e compartilhar"** → **"Instalar página como aplicativo…"**
   (dependendo da versão pode ser **"Mais ferramentas" → "Criar atalho…"** e marcar
   **"Abrir como janela"**).
4. Confirme. Vai aparecer o ícone da Central de Escalas na área de trabalho.

### No Edge
1. Abra o sistema no navegador.
2. Clique nos **três pontinhos** (canto superior direito).
3. Vá em **"Aplicativos"** → **"Instalar este site como um aplicativo"**.
4. Confirme.

Depois é só usar o ícone para abrir direto, como qualquer programa.

---

## Deu erro / não abre?

- **"Não é possível acessar esse site":** o servidor pode estar desligado ou o endereço
  mudou. Avise o responsável pelo sistema.
- **Tela em branco ou travada:** feche e abra de novo, ou aperte **Ctrl + F5** para
  recarregar limpando o cache.
- **Esqueci a senha:** peça a um administrador para redefinir em *Configurações → Usuários*.
