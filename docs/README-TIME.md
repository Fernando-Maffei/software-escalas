# Central de Escalas — como usar

## Como acessar

Abra o navegador (Chrome ou Edge) e digite o endereço do sistema:

```
http://192.168.0.50:4450
```

> Troque `192.168.0.50` pelo endereço que o responsável passou.
> **Dica:** salve nos favoritos para não digitar toda vez.

Faça login com seu usuário e senha. Pronto.

---

## Deixar o sistema com "cara de aplicativo" (ícone na área de trabalho)

O jeito mais fácil: o responsável passa o arquivo **`CRIAR-ATALHO.cmd`**
(pendrive, rede ou e-mail). Dê **dois cliques** nele, digite o endereço do
servidor e pronto: aparece o ícone **Central de Escalas** na área de trabalho e
no menu Iniciar. Ele abre o sistema numa **janela própria**, sem a barra do
navegador, como um programa. Não instala nada e não pede senha de administrador.

- Para fixar na barra de tarefas: abra pelo ícone, clique com o botão direito no
  ícone da barra e escolha **Fixar**.
- O servidor mudou de endereço? Rode o `CRIAR-ATALHO.cmd` de novo.

<details>
<summary>Sem o arquivo: criando o atalho pelo navegador</summary>

**No Edge:** três pontinhos → **Aplicativos** → **Instalar este site como um
aplicativo** → confirmar.

**No Chrome:** três pontinhos → **Salvar e compartilhar** → **Instalar página
como aplicativo…** (em versões antigas: **Mais ferramentas → Criar atalho…** e
marcar **Abrir como janela**).

</details>

## Deu erro / não abre?

- **"Não é possível acessar esse site":** o servidor pode estar desligado ou o endereço
  mudou. Avise o responsável pelo sistema.
- **Tela em branco ou travada:** feche e abra de novo, ou aperte **Ctrl + F5** para
  recarregar limpando o cache.
- **Esqueci a senha:** peça a um administrador para redefinir em *Configurações → Usuários*.
